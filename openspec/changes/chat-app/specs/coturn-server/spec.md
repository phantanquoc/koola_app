## ADDED Requirements

### Requirement: Coturn Installation
The system SHALL run Coturn as a Docker container on Proxmox VM3 for TURN/STUN functionality.

#### Scenario: Coturn container running
- **WHEN** VM3 is provisioned
- **THEN** Coturn Docker container is started with ports 3478/UDP and 3478/TCP exposed to host; Coturn listens on all network interfaces

### Requirement: Coturn Authentication
The system SHALL use long-term credential authentication for TURN relay.

#### Scenario: TURN authentication
- **WHEN** WebRTC client attempts to use TURN relay
- **THEN** Coturn validates credentials using `static-auth-secret` in coturn.conf; credentials are generated by NestJS using `turn 오` format with expiry

#### Scenario: Credential generation
- **WHEN** NestJS generates ICE server config for a call session
- **THEN** TURN credentials are generated with format: username = `<timestamp>:<targetUserId>`, password = HMAC-SHA1(static-auth-secret, username), TTL = 3600 seconds

### Requirement: STUN Server
The system SHALL provide STUN service for clients to discover their public IP addresses.

#### Scenario: STUN discovery
- **WHEN** WebRTC client includes `stun:<coturn-public-ip>:3478` in ICE servers
- **THEN** Coturn responds with the client's public IP address (binding request/response)

### Requirement: TURN Relay for Failed P2P
The system SHALL relay media through TURN when direct P2P connection cannot be established.

#### Scenario: TURN relay active
- **WHEN** WebRTC peer connection fails to connect via P2P (all ICE candidates failed)
- **THEN** clients fall back to TURN relay; all media streams flow through Coturn server

#### Scenario: TURN bandwidth monitoring
- **WHEN** TURN relay is in use
- **THEN** Coturn tracks bandwidth per user; logs warning if a single user exceeds 10Mbps relay bandwidth

### Requirement: Coturn Configuration
The Coturn server SHALL be configured with the following settings:

```
listening-port=3478
tls-listening-port=3478
realm=<domain-or-public-ip>
fingerprint
lt-cred-mech
static-auth-secret=<secret>
total-quota=100
bps-capacity=10000000
```

### Requirement: Firewall Configuration
The system SHALL configure Proxmox firewall to allow TURN/STUN traffic.

#### Scenario: Firewall rules
- **WHEN** VM3 firewall is configured
- **THEN** UDP port 3478 and TCP port 3478 are allowed from any source (STUN/TURN is public by design)

### Requirement: Coturn Monitoring
The system SHALL monitor Coturn for uptime and relay usage.

#### Scenario: Health check
- **WHEN** GET /health includes infrastructure check
- **THEN** NestJS health check verifies Coturn is reachable on port 3478
